# Telegram Order Bot — Aiogram 3.31.0

Готовый бот-заказчик на Python + Aiogram 3.31.0 с визуальными меню и JSON-базой.

## Возможности

- Главное меню 2 колонки.
- Профиль пользователя.
- Заказ бота / сайта / игры / приложения через FSM-анкету.
- Заказы отправляются администраторам с inline-кнопками.
- Принять заказ: администратор указывает название проекта и стоимость.
- Отказать: администратор вводит причину.
- Пользователь видит принятые заказы и может нажать «Выполнил заказ».
- После выполнения пользователь оставляет текстовый отзыв и оценку 1–5.
- Отзыв и выполненный заказ публикуются в канал.
- Список заказов и текущие статусы.
- Ценники.
- Техподдержка.
- Настройка уведомлений ON/OFF.
- Бан на 7/14/28 дней или навсегда.
- /ban, /unban, /profile, /prim_zakaz, /otkaz_zakaz.
- Всё хранится в JSON.

## Установка

Python 3.10+ (рекомендуется 3.13/3.14).

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

Запустите `main.py`. При первом запуске автоматически создастся `config.json`.
Откройте его и заполните:
- `BOT_TOKEN`
- `ADMIN_IDS`
- `REVIEWS_CHANNEL`
- при необходимости `CONTACT_USERNAME`

После этого снова запустите:

```bash
python main.py
```

Бот должен иметь право публиковать сообщения в `REVIEWS_CHANNEL`.

## Админ-команды

`/ban id/@Username 7d`
`/ban id/@Username 14d`
`/ban id/@Username 28d`
`/ban id/@Username Owers`

`/unban id/@Username`

`/profile` или `/profile id/@Username`

`/prim_zakaz 123`

`/otkaz_zakaz 123`

После `/prim_zakaz` бот запросит название проекта и стоимость.
После `/otkaz_zakaz` бот запросит причину.

## Важные замечания

1. JSON удобен для небольшого бота. Для большого количества пользователей лучше заменить слой хранения на PostgreSQL/SQLite.
2. Бот не может написать пользователю первым: пользователь должен хотя бы один раз открыть/запустить бота.
3. Для канала используйте @username публичного канала или корректный numeric chat_id.
4. Токен не храните в GitHub и не публикуйте. Файл `config.json` также не публикуйте.
